# Fluxo

MVP do Fluxo, sistema de logística desenvolvido como projeto extensionista da UEMG Frutal.

Reúne numa só tela pedidos, estoque, rotas de entrega e cobrança por Pix, pensado para pequenos produtores e comércios de Frutal que hoje controlam entregas por WhatsApp e planilha.

O sistema é um único arquivo, `index.html`, que roda direto no navegador, sem instalação.
